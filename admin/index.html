Postman accounts

This server can't store keys yet. Set a SECRET_KEY secret of at least 32 random characters (openssl rand -hex 32), then come back.

Connect a Postman account

  1. Create an API key in Postman's API key settings.
  2. Add it here. Its workspaces appear in Dispatch straight away.
  3. Choose who gets which workspace. Changes sync both ways, so people on Postman and on Dispatch share the same work.
